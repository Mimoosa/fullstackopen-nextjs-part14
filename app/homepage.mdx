# Welcome to Blog app

A modern blogging platform built with Next.js.
Create, manage, and explore blog posts with a clean interface and smooth user experience.

## Features

- Create and manage blog posts
- User profiles
- Authentication
- Comments
- Clean and modern UI

## Getting Started

To start exploring:

1. [Register](https://fullstackopen-nextjs-part14.vercel.app) for a new account
2. [Login](https://fullstackopen-nextjs-part14.vercel.app/register)
3. [Create a new blog post](https://fullstackopen-nextjs-part14.vercel.app/blogs/new)
4. View [all blogs](https://fullstackopen-nextjs-part14.vercel.app/blogs) and [users](https://fullstackopen-nextjs-part14.vercel.app/users)

This app is built using Next.js, React, and Drizzle ORM.
Source code: [https://github.com/Mimoosa/fullstackopen-nextjs-part14.git](https://github.com/Mimoosa/fullstackopen-nextjs-part14.git)
